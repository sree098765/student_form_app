# Student Form App

A Flask web application that allows students to submit project details and stores the data in an Excel file.

---

## 📌 Features
- Student project submission form
- Automatic Excel data storage
- Flask template support
- Clean and simple UI

---

## 🛠️ Tech Stack
- Python
- Flask
- HTML
- CSS

---

## 📂 Project Structure
student_form_app/
│── app.py
│── requirements.txt
│── README.md
│── .gitignore
│── templates/
│   ├── form.html
│   └── google_form.html

---

## ▶️ How to Run
1. Install Python  
2. Install dependencies  
   pip install -r requirements.txt  
3. Run the app  
   python app.py  
4. Open browser  
   http://127.0.0.1:5000
